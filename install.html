install guide · v0.1 beta

get it.
tap it.

idkvideos installs from your browser. No app store needed. Make sure you're online, then open the app below.

Open idkvideos ↗

iPhone / iPad

  1. Open this website in Safari.
  2. Tap the Share button.
  3. Choose Add to Home Screen, then tap Add.
  4. Launch idkvideos from your Home Screen.

Android

  1. Open this website in Chrome.
  2. Tap the three-dot menu.
  3. Choose Install app or Add to Home screen.
  4. Launch idkvideos from your app list or Home Screen.

Windows / macOS / Chromebook

  1. Open this website in Chrome or Edge.
  2. Use the install icon in the address bar, or the browser menu's Install app option.
  3. Pin it wherever you like.

First use: open Settings in idkvideos and add your YouTube Data API v3 key. If your friends use the same key, protect it and remember that all of you share its quota. This static GitHub Pages version does not hide API keys in the browser.
